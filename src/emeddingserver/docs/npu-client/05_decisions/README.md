# Architecture Decisions (ADR)

Record major technical decisions and context.

## Naming

Use: `ADR-XXXX-short-title.md`.

## Required Sections

1. Status (proposed, accepted, deprecated)
2. Context
3. Decision
4. Consequences
5. Alternatives considered
