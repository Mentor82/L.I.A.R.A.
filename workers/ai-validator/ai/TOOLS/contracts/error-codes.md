# error-codes

Standard error code list for tools.

## Codes
- INVALID_INPUT: Input fails schema validation.
- UNAUTHORIZED: Permission denied or missing authorization.
- NOT_FOUND: Requested resource not found.
- CONFLICT: State conflict or race detected.
- RATE_LIMITED: Too many requests.
- TIMEOUT: Operation exceeded allowed time.
- INTERNAL_ERROR: Unexpected internal failure.

## Notes
- Tool-specific error codes are allowed but must be documented.
