# DATA-GOVERNANCE

This policy defines how data is handled when using AI tools in this repo.

## Scope
- Applies to prompts, outputs, and artifacts generated by Codex and Copilot.
- Covers local files, logs, and examples in documentation.

## Data classification
- Public: OK to include.
- Internal: Use only when necessary; avoid broad reuse.
- Sensitive: Do not include in prompts, examples, or logs.
- Secrets: Never include or persist.

## Source of truth
- Prefer `docs/*.md` for UI and content generation.
- Only use data from the repo or explicitly provided by the user.

## Minimization and redaction
- Use the least amount of data needed to solve the task.
- Redact identifiers, credentials, tokens, and personal data.
- Replace sensitive values with placeholders when needed.

## Storage and retention
- Do not store sensitive data in repo files.
- Avoid embedding real data in test fixtures or examples.
- Keep generated artifacts minimal and necessary for the task.

## Sharing and external access
- Do not send data to external services without user approval.
- Respect `network_access` constraints and project policies.

## Compliance
- If a policy conflict exists, follow the stricter rule.
- Ask for clarification when data sensitivity is unclear.
