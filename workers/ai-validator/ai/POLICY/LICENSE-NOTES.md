# LICENSE-NOTES

Notes about licensing expectations for AI-assisted work.

## Scope
- Applies to Codex and Copilot outputs in this repository.
- Covers code, text, and assets generated or modified by AI.

## Rules
- Do not copy external code or content without a compatible license.
- Prefer original phrasing; avoid verbatim reuse from unknown sources.
- Preserve existing license headers and attribution notices.
- When adding new third-party content, document the license and source.

## Documentation
- Record license sources in relevant docs or `NOTICE` files if present.
- If unsure about licensing, ask for clarification before proceeding.
