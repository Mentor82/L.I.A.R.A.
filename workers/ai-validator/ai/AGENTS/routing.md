# routing

## Routing principles
- Use the minimal set of agents needed for the task.
- Prefer clarity and policy alignment over speed.
- If a policy conflict is detected, escalate to the reviewer.

## Quick routing guide
- Ambiguous scope or approach choice -> thinker
- Implementation or edits -> executor
- Risk, bugs, or verification -> reviewer
- Docs or consistency -> curator
- Summaries and next steps -> narrator
- Multi-step or complex work -> planner
- Context/policy checks -> observer

## Escalation triggers
- Security-sensitive changes
- Data handling uncertainty
- Incomplete requirements
- Conflicting sources of truth
